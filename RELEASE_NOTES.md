## Mac – erster Start

DMG öffnen und `LellekClient` auf „Programme“ ziehen. Dann Rechtsklick auf die App → „Öffnen“ → „Öffnen“.
Meldet macOS „beschädigt“, einmal im Terminal: `xattr -cr /Applications/LellekClient.app`

Prüfsummen: `SHA256SUMS.txt`
